O que pode estar ocorrendo?
• Segurança do Navegador (Bloqueio CORS): Rodar este painel direto do seu computador usando file:/// bloqueia o carregamento por segurança. Utilize um servidor web local ou extensão como Live Server no VS Code.
• Configurações da Planilha: Certifique-se de que a planilha do Google foi publicada usando o menu Arquivo > Compartilhar > Publicar na Web e configurando o formato de exportação para CSV (Valores separados por vírgula).
